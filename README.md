# 驿满连接

优先下载 [驿满连接 2.0.5 主安装包](https://github.com/aufrichttang/yiman-connect-releases/releases/download/v2.0.5/YimanConnect-2.0.5.exe)。

主安装包已内置 WireGuard，会自动检查并按需安装。安装完成后使用已获授权的 V3 账号密码登录，无需导入 VPN 配置。

[发布说明与备用组件](https://github.com/aufrichttang/yiman-connect-releases/releases/tag/v2.0.5)

**WireGuard 单独 MSI 仅备用**，供排障或管理员手动安装使用。正常安装不需要先运行它。Windows Installer 错误 1601 需修复系统安装服务，备用 MSI 无法绕过此依赖。

适用于 Intel / AMD 64 位 Windows 10、11，需 .NET Framework 4.8。当前为试点预发布，目标 Windows 10 完整安装验收仍待完成。
